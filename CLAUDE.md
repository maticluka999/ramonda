When making changes, use these commands for checking them:

- for typechecking the project: "npm run typecheck"
- for building the project: "npm run build"
- for cleaning the build output: "npm run clean"
- for running tests: "npm run test"
- for running E2E tests: "npm run test:e2e"
- for formatting the changes: "npm run format" -> no need to check formatting, feel free to always format all the files you edited
